# NetBox + Terraform + Git Learning Lab

Use the [step-by-step study guide](./STUDY_GUIDE.md) to learn NetBox,
Terraform, and Git progressively against the test NetBox at `https://172.16.4.4`.

The root Terraform configuration currently has no NetBox resources, so it
will not recreate the practice site that was deleted. Do not add resources or
run `terraform apply` until you are following the corresponding lesson and
have reviewed the plan.
